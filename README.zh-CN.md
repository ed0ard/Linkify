## 安装

1. **获取压缩包**

&nbsp;&nbsp;&nbsp;&nbsp;从 [发布页](https://github.com/ed0ard/Linkify/releases/latest) 下载最新版 `Linkify.zip`。

2. **打开扩展程序页面**

- Edge：在地址栏输入 `edge://extensions`，按下回车键。

- Chrome：在地址栏输入 `chrome://extensions`，按下回车键。

- Firefox：在地址栏输入 `about:debugging#/runtime/this-firefox`，按下回车键。

3. **开启开发人员模式**（仅 Edge 和 Chrome 需要此步骤）

&nbsp;&nbsp;&nbsp;&nbsp;打开页面右上角的 **开发人员模式** 开关。

4. **从压缩包安装扩展**

- Edge 和 Chrome：将 `Linkify.zip` **拖拽**到扩展程序页面后**松开**鼠标。
  若浏览器弹出添加扩展的确认提示，请确认允许。

- Firefox：点击 **临时载入附加组件**，选中 `Linkify.zip` 文件。
